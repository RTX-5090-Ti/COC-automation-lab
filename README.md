# CoC Vision Automation Lab

Milestone 1 focuses only on ADB connectivity, Clash of Clans process checks, and screenshot capture from BlueStacks.

## Run

Activate the virtual environment, then run:

```powershell
python main.py
```

Optional arguments:

```powershell
python main.py --debug
python main.py --adb-path "C:\Program Files\BlueStacks_nxt\HD-Adb.exe"
python main.py --device-id emulator-5554
```
